How the colour is used

BandScaleColourWhy that colour
KPI points earnedof 80 Status — green / amber / red Measured against a goal, so it keeps the tone language the KPI table already uses.
KPI points missedof 80 Neutral grey The shortfall is the absence of a result, not a second result. Colouring it red would double-count the bad news.
Manager appreciationof 20 Violet — outside the status palette A judgement, not a measurement. A green 20 would read as “hit a target”; violet says “different kind of number”.
Not yet scoredof 20 Hatched slot, labelled Pending Never 0 and never 20. Both are claims. An empty slot is the truth.

Deliberately only one new hue. The board already uses green / amber / red for status, and a fifth status colour would make appreciation look computed.
